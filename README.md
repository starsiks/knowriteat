# 알고 쓰고 먹자 — v1.8

나이스 급식 메뉴를 활용해 쉬운 낱말 따라쓰기 학습지를 만드는 웹앱입니다.

## 배포

1. 이 ZIP 파일을 압축 해제하여 Netlify 사이트에 **폴더 전체**를 배포하거나 Netlify에 ZIP을 배포합니다. `index.html`만 배포하면 학교 검색/급식 조회가 동작하지 않습니다.
2. Netlify **Site configuration → Environment variables**에서 `NEIS_API_KEY`를 등록합니다. 키 값은 웹앱 소스에 포함되어 있지 않습니다. 이미 기존 Netlify 사이트에 이 변수가 있으면 재사용할 수 있습니다.
3. Netlify Functions 사용 환경(배포)이 필요합니다. 단순히 index.html을 PC에서 열면 미리보기와 PDF는 되지만 학교 검색과 급식 조회는 되지 않습니다.
4. 먼저 학교 검색에서 학교를 선택하고 날짜를 고른 뒤, 급식 메뉴와 자동추천 낱말을 확인합니다.

## 주요 기능

- 전국 학교 이름 검색 (`schoolInfo`) 및 점심 급식 조회 (`mealServiceDietInfo`)
- 메뉴의 알레르기 숫자 제거, 최대 9개 표시, 메뉴 직접 입력 지원
- 음식 및 재료 낱말 자동 추천, 클릭으로 수정, 합계 9음절 이내에서는 낱말 개수 제한 없음
- 학생 목록 추가/삭제/선택, 학생별 이름 표시 방식 3종: 점선 / 칸 좌상단 음절 전체 본보기 / 빈칸
- 학생별 따라쓰기/혼자쓰기 줄 수 합계 최대 8, 기본값 6+2
- A4 세로 SVG 미리보기 및 PDF 다운로드: 선택 학생, 빈 이름, 전체 학생 묶음
- 학교와 학생별 설정 브라우저 localStorage 보관 (다른 기기와 공유되지 않음)

## 보안 및 이용 시 주의

- API 키는 반드시 서버의 환경변수로만 저장하세요. 브라우저 코드에는 넣지 마세요.
- 학생 이름은 사용 중인 브라우저에만 저장됩니다. 공용 PC에서는 개인정보에 주의하고 브라우저 데이터를 삭제하세요.
- PDF는 고해상도 비트맵 기반이며, 사용자 PC/휴대전화의 한글 글꼴 렌더링에 따라 점선 모양에 차이가 있을 수 있습니다. 실제 출력하여 확인해 주세요.
- 나이스에 급식이 없는 날은 메뉴를 직접 입력하면 됩니다. 학교별 실제 급식 제공 데이터에 따라 검색 결과가 다를 수 있습니다.
- 단어 추천은 내장 어휘 목록을 바탕으로 하며 AI 모델이 아닙니다. 최종 선택은 교사가 확인하세요.

## v1.2 변경 사항

- 최초 접속 시 예시 학생 **알쓰먹**을 기본으로 등록합니다.
- 이미 학생을 등록한 사용자의 목록은 유지합니다.
- 기본 학생을 삭제해도 다음 접속 시 자동으로 다시 생성하지 않습니다.


## v1.3 변경사항
- 학습지 A4 여백을 상하좌우 각 10mm로 고정했습니다.
- 날짜/이름 표와 낱말 표를 같은 전체 인쇄 폭으로 확장했습니다.
- 낱말 표는 최대 8줄의 연습 영역을 사용하며 기본 6+2줄에서 종이 하단까지 채웁니다.
- 표 글꼴을 궁서체 우선, 미설치 환경에서는 명조 계열로 대체합니다. 글꼴 파일은 동봉하지 않습니다.
- 기존 학생 설정, 학교 선택, API 함수 및 환경변수 설정은 그대로 유지됩니다.


## v1.5 변경 내용
- 학습지 미리보기 종이 컨테이너의 화면 비율을 A4 세로(210:297)로 고정했습니다.
- SVG를 A4 프레임 안에 정확히 맞춰 그리며 PDF와 인쇄용 좌표는 그대로 유지합니다.
- 화면 너비에 따라 A4 비율을 유지하며 축소됩니다.


## v1.6 변경 내용
- 학생별 날짜 제시 방식을 3종(점선, 칸 좌상단 작은 본보기, 빈칸)으로 설정할 수 있습니다.
- 날짜의 월·일 문자는 유지하고 숫자에만 설정을 적용합니다.
- 기본 날짜 방식은 점선 따라쓰기입니다. 기존 학생 데이터에는 누락된 값을 기본값으로 처리합니다.
- 설정은 학생별 브라우저 저장 및 선택 학생/전체 학생 PDF 출력에 반영됩니다.

## v1.7 변경사항 (획 중심선 점선 시험판)
- '④ 학생별 쓰기 설정'의 순서를 학습지와 동일하게 **날짜 → 이름 → 쓰기 줄 수**로 변경했습니다.
- 기존 글꼴 외곽선에 점선을 그리는 대신, 한글 완성형 음절을 초성·중성·종성으로 분해한 뒤 직접 설계한 자모 중심 획을 SVG 점선으로 조합합니다.
- 날짜의 숫자(0–9)도 중심 획 점선으로 표시합니다.
- 학생 이름, 날짜, 급식 낱말의 점선에 동일한 방식을 사용합니다. 인쇄·PDF는 기존 SVG 렌더링 흐름을 그대로 사용합니다.
- 직접 설계한 단순화된 중심선 문자이므로 실제 손글씨 폰트와 글자꼴이 완전히 일치하지 않을 수 있습니다. 특히 겹받침이나 복합모음은 실제 학습지 인쇄 후 확인을 권장합니다.
- 기존 Netlify Functions, `NEIS_API_KEY` 환경변수, 학교 및 학생 브라우저 저장 방식은 유지합니다.

- 점선 글자 전체에 엘점선체 웹폰트를 자체 탑재했습니다 (날짜, 이름, 급식 낱말). 이전 SVG 자모 조합 코드는 제거했습니다.
- fonts/ElDot.woff2 (웹용 압축 글꼴) 및 fonts/ElDot.ttf (원본), OFL.txt를 포함합니다. 제작 정보: https://blog.naver.com/cgsjw/224354331923

- 기존 학교 검색/나이스 API/학생별 설정, 9음절 제한은 유지됩니다.
