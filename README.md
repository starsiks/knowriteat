# 알고 쓰고 먹자 v2.3 — Netlify + Vercel 겸용

업데이트: **2026-11-19**

학교 급식 메뉴를 활용하여 읽기·쓰기·말하기를 생활 경험에 연결하는 학습지 제작 웹앱입니다. v1.8의 학습지/엘점선체/PDF 기능을 유지합니다.

## 파일 구조

- `index.html`, `app.js`: **공통** 화면 및 학습지 기능
- `fonts/`: 엘점선체 및 점선 글리프 경로 데이터 (OFL.txt 확인)
- `lib/neis.mjs`: **공통** 학교 검색 및 급식 조회 처리 로직
- `netlify/functions/`: Netlify 서버 함수 진입점
- `api/`: Vercel 서버 함수 진입점
- `netlify.toml`: Netlify에서 `/api/schools`, `/api/meals` 요청을 서버 함수로 전달
- `OFL.txt`: 점선 글꼴 라이선스

두 플랫폼 모두 브라우저에서 `/api/schools?q=학교명`, `/api/meals?region=교육청코드&school=학교코드&date=YYYYMMDD`를 호출합니다. NEIS 키는 서버에서만 조회합니다.

## Netlify 배포

1. 프로젝트 최상위의 `index.html`이 배포 루트에 있도록 배포합니다. ZIP은 **루트에 파일이 들어 있는 형태**입니다. 기존 사이트에 덮어 배포할 수 있습니다.
2. 사이트 환경변수 `NEIS_API_KEY`를 `Functions` 범위 및 `Production` 문맥에 설정합니다. 이미 설정했다면 그대로 사용합니다.
3. `netlify.toml`을 포함해 배포합니다. Netlify Functions가 배포되어야 학교 검색/급식 조회가 동작합니다.
4. `/api/schools?q=상록초`로 확인하거나 웹페이지에서 학교 검색을 시험합니다.

## GitHub → Vercel 배포

1. ZIP을 풀어 **전체 파일과 폴더**를 GitHub 저장소 최상위에 업로드합니다. `api/`, `lib/`, `fonts/` 포함. `NEIS_API_KEY` 값은 절대로 GitHub에 올리지 않습니다.
2. Vercel에서 해당 GitHub 저장소를 Import합니다. Framework Preset은 `Other`(일반 정적 사이트)로 사용할 수 있습니다. Root Directory는 프로젝트 루트(`./`)로 설정합니다. 별도의 빌드 명령이나 `vercel.json`은 필요하지 않습니다.
3. Vercel 프로젝트의 Environment Variables에 `NEIS_API_KEY`를 **Secret**으로 등록합니다. Production에 필수로 적용하고, Preview/Development는 필요 시 선택합니다.
4. **새 배포**를 실행하고 학교 검색과 급식 조회를 확인합니다.

## 확인 사항

- 앱에서 학생 목록·학교·쓰기 설정은 브라우저 localStorage에 보관됩니다. 기존 v1.x 저장 키를 그대로 사용하므로 저장된 학생 설정을 유지합니다. 다른 도메인(Netlify↔Vercel)의 저장 데이터는 자동으로 공유되지 않습니다.
- 프론트엔드 공통 코드, 점선체, A4 비율, 날짜 및 이름 제시 방식, 최대 9음절, 따라쓰기 6줄 + 혼자쓰기 2줄(합계 최대 8줄), PDF 기능을 유지합니다.
- 웹앱의 점선 글꼴 출처 안내 **아래**에 버전 `v2.2.3` 및 업데이트일 `2026.11.24.`를 표시합니다. 이 문구는 PDF에는 포함되지 않습니다.
- 엘점선체 제작자 출처: https://blog.naver.com/cgsjw/224354331923
- 학교검색·급식조회에는 나이스 OpenAPI가 필요하며 네트워크와 나이스 서비스 상태에 영향을 받습니다.
- API 키가 대화에서 공유된 적이 있다면 공개 배포 전에 재발급·교체를 권장합니다.

## v2.2.3 Netlify 테스트 버전 (GitHub/Vercel 미반영)
- PC에서는 학교·메뉴(왼쪽), 학생별 설정(가운데), A4 미리보기(오른쪽) 3단 구성을 사용합니다. 작은 화면은 2단/1단으로 바뀝니다.
- 학습지 유형: 낱말 쓰기(기존 9음절 제한) / 문장 쓰기(최대 5개 메뉴, 9음절 제한 없음).
- 문장 쓰기형은 메뉴명을 예시문의 초기값으로 사용합니다. 예시문을 고치거나 비울 수 있고, 쓰기 칸의 좌상단에 표시합니다.
- 공통 예시문과 학생별 개별 예시문을 각각 편집합니다. 학생별로 빈칸을 지정하거나 '공통값' 버튼으로 복귀할 수 있습니다.
- 같은 날짜에 저장된 예시문 설정은 브라우저에 보관되며 다른 날짜를 선택하면 새로 시작합니다. 학생 목록/기존 설정의 localStorage 키는 유지합니다.
- 빈 이름 PDF 버튼을 삭제했습니다. 선택 학생 PDF 및 전체 학생 PDF는 유지합니다.
- Netlify에 ZIP 그대로 배포하고 `NEIS_API_KEY` 환경변수는 기존 값을 사용합니다.
- 테스트 용도이므로 GitHub/Vercel에는 아직 반영하지 않습니다.
- 자체 포함한 나눔고딕 Regular WOFF2는 브라우저 호환성을 위해 문제가 되는 내부 TSI 테이블을 제거하고 다시 변환했습니다.

테스트할 내용: 문장 쓰기형 메뉴 선택·예시문 공통 편집·학생별 개별 편집·학생 전환·PDF 두 종류·기존 낱말 쓰기형.
